# Interplanetary Network

Лабораторная работа № 3. Неориентированный граф.

## Техническое задание

Реализовать на C++17 универсальный АТД простого невзвешенного неориентированного графа. Граф создаётся пустым или по спискам вершин и рёбер. Он поддерживает добавление, удаление, поиск и перечисление вершин и связей. Повтор ключа или ребра, петля и ребро с отсутствующей вершиной отклоняются с указанием причины. Удаление вершины удаляет её инцидентные рёбра.

Выбранные варианты — М‑1.2 (6), М‑2.5 (6), М‑2.6 (4), М‑3.1 (10). Суммарный рейтинг — 26.

- BFS и DFS показывают порядок посещения. Поиск остова использует выбранный обход и стартовую вершину. Для связного графа результат содержит все вершины и V−1 ребро. Пустой и несвязный графы имеют отдельные результаты.
- Поиск компонент связности охватывает все вершины. Изолированная вершина образует отдельную компоненту.
- Генератор поддерживает цепочку, цикл (n ≥ 3), полный граф, звезду (n ≥ 1), двоичное дерево (n ≥ 1) и случайный граф. Для случайного графа задаются n, m и seed. Число рёбер удовлетворяет 0 ≤ m ≤ n(n−1)/2.
- Прикладная задача моделирует межпланетную сеть. Ключ задаёт идентификатор станции, ребро — доступный двусторонний канал. Анализ показывает зоны связности и минимальный по числу каналов набор для связной сети.
- Графическое приложение принимает ручные и сгенерированные данные, визуализирует обходы и отказы, сравнивает BFS и DFS и сохраняет измерения в CSV. Библиотека и тесты собираются отдельно от интерфейса.

## Сборка и запуск

Команды выполняются в корне проекта. Для графического приложения нужны macOS, Metal и Command Line Tools с C++17. Dear ImGui, GLFW и шрифт Droid Sans лежат в проекте вместе с лицензиями.

| Команда | Результат |
|---|---|
| make | Собирает пакет Interplanetary Network.app в build |
| make run | Собирает и открывает приложение |
| make gui | Собирает только графическое приложение |
| make run_tests | Собирает и выполняет автоматические тесты |
| make check | Запускает тесты с AddressSanitizer и UndefinedBehaviorSanitizer |
| make run_benchmark | Сравнивает два обхода для обеих задач на циклах из 100 и 1000 вершин |
| make clean | Удаляет каталог сборки |

Собранный пакет Interplanetary Network.app можно открыть из Finder.

Отдельный замер можно запустить командой ниже после сборки цели benchmark.

    ./build/benchmark random 1000 7 components 3000 19

Параметры идут в порядке «топология, n, повторы, задача». Для random в конце передаются m и seed. Имена топологий — chain, cycle, complete, star, binary_tree, random. Задачи — spanning_tree и components.

## Архитектура и контракты

Библиотека графа инкапсулирует словарь key → index и последовательность записей вершин. Списки смежности содержат индексы. Чтение для обходов идёт через Graph, поэтому внутри цикла обработки соседей обращения к словарю не нужны. Генератор выдаёт списки вершин и рёбер. Графический интерфейс передаёт их графу и выбирает реализации хранения. Прикладной режим использует тот же граф со строковыми ключами.

Для выбора последовательностей извне конструктор принимает два указателя на функции. Функции возвращают отдельные пустые последовательности и вызываются при создании графа и списков соседей. Например, экземпляр с числовым ключом можно собрать так.

    Graph<std::size_t> graph(std::make_unique<TreeDictionary<std::size_t, std::size_t>>(),
                             CreateArraySequence, CreateArraySequence);

CreateArraySequence — обычный шаблон функции. Компилятор выводит обе специализации из сигнатуры конструктора. Запись вершины и её указатель объявлены в закрытой части Graph.

Локальный интерфейс Sequence предоставляет RemoveAt. Для отката используются последовательности индексов и указателей на записи. По действительному индексу ArraySequence удаляет такие элементы без выделения памяти. Добавление вершины откатывает последнюю запись при отказе словаря. Добавление ребра откатывает запись у первого конца при сбое у второго. Счётчик рёбер меняется после обеих записей. Удаление вершины подготавливает полный новый граф и затем подменяет состояние. Альтернативная реализация хранения должна сохранять содержимое при неудачном Append или Add и удалять элементы этих двух типов по действительным индексам без исключений.

Ключ должен копироваться при конструировании и удовлетворять контракту словаря. TreeDictionary поддерживает явный компаратор строгого слабого порядка. ArrayStorage поддерживает ключи std::size_t. DynamicArray создаёт и присваивает элементы массива, поэтому для непосредственного хранения ключей в ArraySequence<Key> нужны конструктор по умолчанию и копирующее присваивание. Внутри графа и в результатах копируются указатели, так что самого ключа это ограничение не касается. Для массового ввода таких ключей можно передать читаемую через Sequence последовательность на готовых данных, как в тесте TestKeyTypes.

Внешние индексы действительны в текущем состоянии графа. В частности, удаление вершины перенумеровывает последующие записи. Результаты обхода владеют собственными копиями ключей. Рёбра остова хранят позиции внутри порядка обхода результата, а границы компонент — позиции за концами групп в общем списке.

| Операция | Оценка для TreeDictionary и ArraySequence |
|---|---|
| Поиск по ключу | O(log(V+1)) времени, O(1) дополнительной памяти |
| Чтение соседа по позиции | O(1) |
| Перебор списка соседей | O(d+1) |
| BFS, DFS, остов и компоненты | O(V+E) времени, O(V) дополнительной памяти |
| Удаление вершины с обновлением индексов | O(V log(V+1)+E) времени, O(V+E) дополнительной памяти |

Оценки предполагают постоянную стоимость сравнения и копирования ключа. Активные данные занимают O(V+E), причём динамические массивы могут сохранять запас выделенной памяти после удаления рёбер. Для BFS последовательность с индексом головы исключает сдвиги при извлечении. DFS использует стек кадров с позицией следующего соседа.

## Работа с приложением

### Межпланетная сеть

При первом запуске открывается демонстрационная сеть из 10 станций и 12 каналов. Для нового сценария выберите «Новая пустая сеть» или «Создать по спискам…». Для ключей с пробелами разделяйте два конца ребра табуляцией. Станцию можно разместить на планете или на её орбите.

Прокрутка масштабирует карту вокруг курсора. Перетаскивание с пробелом или правой кнопкой перемещает камеру. Перетаскивание станции меняет её положение на карте. Канал можно создать через два списка в секции «Добавить канал» или двумя щелчками в режиме «Соединить на карте». Выбранные станции и каналы видны в инспекторе, где их можно удалить.

В секции «Анализ» выберите BFS или DFS и тип операции. Для остова и обычного обхода укажите начальную вершину. В инспекторе доступны порядок, пауза, продолжение, шаг вперёд, повтор, сброс и скорость. Для остова можно оставить на карте только его рёбра, а для компонент — выделить группу и посмотреть её состав.

Для проверки отказа начните эксперимент и выберите канал **Фобос — Юпитер** в списке «Каналы». Удобно ввести «Фобос» в поиск. «Отключить канал» разделит исходную группу на две группы по пять станций. «До» и «После» переключают отображаемую сеть. «Завершить эксперимент» возвращает исходную конфигурацию. В одном опыте моделируется отказ одного объекта. «Сбросить отказ» готовит исходную копию для следующего опыта.

### Генератор графов

Выберите одну из шести топологий и задайте размер. В случайной топологии доступны число рёбер и seed. «Повторить параметры» воспроизводит граф и размещение. Обычный граф можно построить и вручную, редактировать и анализировать. Действие «Использовать как сеть…» показывает параметры переноса и запрашивает подтверждение перед заменой сети.

Для полной сцены используется бюджет 300 вершин и 3000 рёбер. В крупном графе карта показывает подмножество и его размер. Выбор вершины показывает её окрестность, выбор группы ограничивает сцену компонентой. Анализ и замеры используют весь граф.

### Производительность

Замеряйте текущую сеть или обычный граф, либо создайте серию по вершинам, рёбрам или нескольким топологиям. Для текущего непустого графа при поиске остова выберите начальную вершину. Сгенерированные графы используют вершину 1. Выберите порядок рёбер и число повторов. Параметры и источники сохраняются для сравнения выполненных серий в текущем сеансе.

Точка на графике или строка в таблице открывает сравнение BFS и DFS для одного входа. Ось X переключается между V, E и V + E. В деталях показаны медианы, минимумы, максимумы, посещённые вершины и сырые измерения. «Экспорт CSV…» позволяет выбрать имя файла и папку в системном диалоге.

## Протокол замеров

В каждом повторе оба обхода работают на одном графе и с одним стартом для остова. Порядок их запуска чередуется. Замер включает обход и формирование результата. Генерация, построение графа, подготовка начального индекса, проверка, расчёт медианы и вывод выполняются вне замера. В серии исходные рёбра передаются в прямом, обратном и воспроизводимо перемешанном порядке.

CSV содержит задачу, алгоритм, топологию, V, E, параметры генерации и перемешивания, порядок рёбер, ключ старта, номер повтора и время в миллисекундах. Для каждой пары BFS и DFS в CSV приходится один номер повтора. Экспорт из приложения также содержит серию, источник, число компонент, число посещённых вершин и состояние графа. Остановка сохраняет пары, завершённые до остановки.
